## 📚 Descripción

Un carrusel de imágenes moderno construido con **JavaScript puro** (sin jQuery ni bibliotecas externas). Perfecto para aprender cómo crear sliders interactivos.

### 🎯 Lo que aprenderás

- ✅ Manipulación del DOM
- ✅ Eventos en JavaScript
- ✅ setInterval para animaciones
- ✅ Transiciones CSS
- ✅ Navegación con teclado

---

## 🚀 Características

| Feature | Description |
|---------|-------------|
| 🔄 Auto-play | Cambia automáticamente cada 3s |
| 👆 Click controls | Botones prev/next |
| ⌨️ Keyboard | ← → para navegar |
| ⏸️ Play/Pause | Detener/Reanudar |
| 📱 Responsive | Se adapta a mobile |
